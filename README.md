# calculator
# 🧮 Streamlit 간편 계산기 프로그램

Python과 Streamlit을 활용하여 웹 브라우저 환경에서 간편하게 사용할 수 있는 기본 사칙연산 계산기입니다.

---

## 🛠 주요 기능 및 특징
- **직관적인 UI**: `Streamlit`을 활용해 웹 화면에서 바로 입력 및 결과 확인 가능
- **예외 처리**: 
  - 정수가 아닌 값이 입력되었을 때 오류 메시지 출력
  - 0으로 나누기 시도 시 예외 처리 (`ZeroDivisionError`)
  - 허용되지 않은 연산자(`+, -, *, /` 외) 입력 시 오류 안내
- **간결한 코드**: 클래스 없이 절차적 프로그래밍 방식으로 최대한 가볍고 이해하기 쉽게 구현

---

## ⚙️ 사전 요구사항 (Prerequisites)
프로그램을 실행하려면 파이썬(`Python`)이 설치되어 있어야 합니다.

---

## 🚀 설치 및 실행 방법

1. **저장소 클론 또는 파일 다운로드**
   프로젝트 폴더 안에 `app.py`와 `requirements.txt` 파일을 위치시킵니다.

2. **필수 라이브러리 설치**
   터미널(또는 명령 프롬프트)을 열고 아래 명령어를 입력하여 Streamlit을 설치합니다.
   ```bash
   pip install -r requirements.txt
